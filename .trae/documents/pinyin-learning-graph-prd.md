## 1. 项目概述

### 1.1 背景

开发者的女儿正在学习汉语拼音。为了帮助她更直观地理解声母、韵母、声调、汉字之间的关联关系，以及通过多种练习方式巩固学习成果，决定开发一个拼音互动学习 Web 应用。

### 1.2 目标

- 将拼音知识以**力导向图谱 + 卡片**的可视化形式呈现，让学习者直观理解拼音结构。
- 内置多种练习模式（选择题、拼音转汉字、汉字转拼音），巩固学习效果。
- 支持语音朗读，帮助发音学习。
- 兼容手机端与 PC 端，方便随时学习。

### 1.3 项目定位

- **项目名**：拼音学习图谱
- **所属仓库**：zhihr 子项目
- **平台**：Web（响应式，适配手机 + PC）
- **目标用户**：学龄儿童（5-8 岁），以开发者的女儿为核心用户

### 1.4 参考资产

| 资产 | 用途 | 路径 |
|------|------|------|
| 拼音.csv | 基础数据源（1075 条拼音-汉字-组词记录） | `/Users/yq/Downloads/拼音.csv` |
| KnowledgeGraph.jsx | 力导向图谱组件参考 | `miaodu/frontend/src/components/KnowledgeGraph.jsx` |

## 2. 用户画像

### 2.1 核心用户：学龄儿童（开发者女儿）

- **年龄**：5-8 岁
- **能力**：正在学习拼音，已初步认识声母、韵母

- **需求**：
  - 能了解孩子的学习进度
  - 可以陪孩子一起使用，讲解知识点

## 3. 功能需求

### 3.1 模块一：知识图谱浏览（核心）

**优先级**：P0（第一版必须包含）

#### 3.1.1 图谱结构

以力导向图展示拼音知识的三层关联：

```
           ┌─────────────────┐
           │   声母中心节点   │   ← 第一层：声母（如 b, p, m, d 等）
           └────────┬────────┘
                    │
         ┌──────────┼──────────┐
         │          │          │
    ┌────▼────┐ ┌───▼───┐ ┌───▼───┐
    │  韵母   │ │ 韵母  │ │ 韵母  │   ← 第二层：可拼读的韵母
    │   a     │ │  o    │ │  ai   │
    └────┬────┘ └───┬───┘ └───┬───┘
         │          │          │
    ┌────▼────┐ ┌───▼───┐ ┌───▼───┐
    │ 拼音卡片 │ │拼音卡片│ │拼音卡片│   ← 第三层：带声调的完整拼音
    │   bā    │ │  bá   │ │  bǎ   │        + 汉字 + 组词
    └─────────┘ └───────┘ └───────┘
```

#### 3.1.2 节点类型

| 层级 | 节点类型 | 特征 | 交互 |
|------|----------|------|------|
| 1 | 声母节点 | 中心节点，较大，固定居中 | 点击展开可拼韵母 |
| 2 | 韵母节点 | 环绕声母分布 | 点击展开拼音详情 |
| 3 | 拼音卡片节点 | 显示完整拼音+汉字+组词 | 点击弹出详情卡片，播放发音 |

#### 3.1.3 交互功能

- **切换声母**：点击声母节点或通过声母选择器切换当前展示的声母
- **展开/收起**：点击韵母节点展开对应拼音详情
- **拖拽**：图谱节点可拖拽，帮助查看被遮挡的内容
- **缩放**：支持滚轮缩放
- **点击详情卡片**：点击拼音卡片弹出详情浮层，包含：
  - 带声调的完整拼音（大字展示）
  - 对应的汉字
  - 组词示例
  - 播放发音按钮
- **适应视图**：一键还原到最佳缩放比例
- **搜索/筛选**：可通过输入拼音或汉字快速定位

#### 3.1.4 视觉设计

- **配色**：色彩丰富柔和，适合儿童审美，不同声母使用不同色系
- **节点样式**：圆角、带渐变或阴影，字体大而清晰
- **卡片样式**：白底圆角背景，层级清晰
- **标签**：始终显示拼音标签，汉字标签默认显示，可切换显隐
- **背景**：浅色背景，干净不杂乱

---

### 3.2 模块二：选择题练习（P0）

#### 3.2.1 题型

**类型 A：拼音选汉字**
> 显示拼音 `bā`，从 4 个汉字中选择正确的。

**类型 B：汉字选拼音**
> 显示汉字 `八`，从 4 个拼音中选择正确的。

#### 3.2.2 出题逻辑

- 从拼音库中随机抽取合法音节
- 干扰项从同声母或同韵母的音节中选取，保证难度适中
- 错误答案需是合法拼音，避免混淆学习

#### 3.2.3 交互

- 选择后即时反馈（绿色正确/红色错误）
- 显示正确答案（答错时）
- 答完一题自动进入下一题
- 计分显示（答对/总题数）
- 练习结束后显示成绩总结

#### 3.2.4 练习范围

- 可按声母筛选（如只练 b/p/m）
- 可按声调筛选（如只练第一声）
- 随机模式（不限范围）

---

### 3.3 模块三：拼音转汉字（P0）

- 显示一个带声调的拼音
- 用户需在输入框中键入/选择对应的汉字
- 适合已有一定基础的儿童练习书写和认字
- 支持选字模式（从候选字中选择）和键盘输入模式

---

### 3.4 模块四：汉字转拼音（P0）

- 显示一个汉字
- 用户需从多个拼音选项中选择正确的
- 或点击声母+韵母+声调拼出正确读音
- 适合巩固拼音拼读能力

---

### 3.5 模块五：语音朗读（P0）

- 实现方式：浏览器原生 Web Speech API（SpeechSynthesis）
- 触发场景：
  - 点击拼音卡片上的播放按钮
  - 练习中展示正确答案时自动朗读
  - 图谱节点悬停/选中时可选播报
- 后续可升级为更高品质的第三方 TTS

---

### 3.6 模块六：学习记录与进度（P1，后续迭代）

- 记录答对/答错统计
- 展示薄弱知识点（高频错误）
- 可选：按天/周查看学习进度
- 本地存储（localStorage），无需后端

## 4. 数据模型

### 4.1 拼音音节表

来源于拼音.csv，数据模型如下：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `shengmu` | string | 声母（"零声母"表示无声母） | b |
| `yunmu` | string | 韵母 | a |
| `shengdiao` | string | 声调描述 | 1声 |
| `pinyin` | string | 带声调完整拼音 | bā |
| `hanzi` | string | 对应常用汉字 | 八 |
| `zuci` | string | 组词示例 | 八个 |
| `yunmu_category` | string | 韵母分类（单韵母/复韵母/鼻韵母等）| 单韵母 |

### 4.2 图谱节点模型

参考 KnowledgeGraph.jsx 的 GraphNode 接口：

```ts
interface PinyinNode {
  id: string
  label: string
  type: 'shengmu' | 'yunmu' | 'pinyin'
  hanzi?: string
  zuci?: string
  shengdiao?: number
  pinyin?: string
  val: number           // 控制节点大小
  color: string
  x?: number
  y?: number
}
```

## 5. UI/UX 设计原则

### 5.1 儿童友好

- **大按钮、大字体**：儿童手指精细动作尚未完全发育，交互区域需足够大
- **色彩丰富**：使用暖色调为主，搭配柔和色彩
- **图标辅助**：关键操作配图标，降低文字阅读门槛
- **即时反馈**：每次交互都有视觉/听觉反馈

### 5.2 响应式设计

- **手机端（320px+）**：图谱占满屏宽，按钮缩小但保持可点，练习为全屏卡片
- **平板端（768px+）**：图谱加宽，工具栏横向排列，练习卡片带留边
- **桌面端（1024px+）**：图谱居中，两侧留白，详情浮层在右侧显示

### 5.3 交互流畅

- 图谱切换动画流畅，力导向重排过程平滑
- 练习切换无页面跳转感，使用过渡动画
- 语音朗读及时响应

## 6. 技术方案

### 6.1 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端框架 | React 18+ | 与 zhihr 现有技术栈一致 |
| 构建工具 | Vite | 快速开发体验 |
| 图可视化 | react-force-graph-2d + d3-force-3d | 复用已有组件依赖 |
| 语音 | Web Speech API (SpeechSynthesis) | 浏览器原生 |
| 状态管理 | React useState + useReducer | 轻量级，无需额外状态库 |
| 样式 | Tailwind CSS | 与 zhihr 现有样式方案一致 |
| 数据存储 | localStorage | 前端本地存储学习记录 |
| 数据导入 | 静态 JSON / CSV 加载 | 拼音数据本地化，无需后端 |

### 6.4 与现有知识图谱的异同

| 维度 | 妙读知识图谱 | 拼音学习图谱 |
|------|-------------|-------------|
| 层级 | 搜索词 → 书籍 → 知识点 | 声母 → 韵母 → 拼音+汉字 |
| 数据来源 | 后端 API 查询 | 本地静态数据 |
| 交互重心 | 浏览检索 | 学习+练习 |
| 节点视觉 | 简约专业 | 卡通色彩丰富 |
| 额外功能 | 无 | 练习模式、TTS 朗读、学习记录 |

- [ ] 点击播放按钮发出正确读音

## 附录 A：术语表

| 术语 | 说明 |
|------|------|
| 声母（Initial） | 汉语拼音开头的辅音，如 b, p, m, d 等 |
| 韵母（Final） | 汉语拼音中声母后的部分，如 a, o, ai, an 等 |
| 声调（Tone） | 汉语拼音的四种声调（1-4声） |
| 整体认读音节 | 不需拼读直接认读的音节，如 zhi, chi, shi 等 |
| 力导向图 | 通过模拟物理力计算节点位置的图可视化布局 |
| TTS | Text-to-Speech，文本转语音 |
| 零声母 | 没有声母的音节，如 ā（啊）、é（鹅） |
