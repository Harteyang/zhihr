# 拼音学习图谱 redesign 设计文档

> 文档版本：v1.0
> 创建日期：2026-07-08
> 状态：待实现

---

## 1. 设计目标

本次 redesign 聚焦两个体验优化方向：

1. **层级色彩方案重设计**：替代当前蓝/绿/橙高饱和配色，采用更柔和、统一、符合儿童审美的层级色彩系统。
2. **韵母点击交互重构**：将「弹窗展示汉字」改为「界面内扇形放射展开汉字节点」，使交互更自然、更符合力导向图的视觉语言。

---

## 2. 色彩方案

### 2.1 设计原则

- **按层级统一颜色**：声母、韵母、拼音三个层级各自使用统一颜色，不再按单个声母分配不同颜色。
- **柔和低饱和**：采用马卡龙色系，降低视觉疲劳，适合儿童长时间使用。
- **层级区分清晰**：三个主色在色相上均匀分布，确保一眼可辨。
- **良好对比度**：节点内文字统一使用白色，确保在彩色背景上清晰可读。

### 2.2 色值规范

| 层级 | 颜色名称 | 色值 | 应用场景 |
|------|----------|------|----------|
| 声母层 | 珊瑚粉 | `#FF9AA2` | 中心声母节点、声母选择器选中态 |
| 韵母层 | 薄荷绿 | `#B5EAD7` | 韵母节点、韵母展开时的连接线高亮 |
| 拼音层 | 奶油黄 | `#FFDAC1` | 拼音+汉字节点、详情卡片强调色 |
| 背景色 | 暖米白 | `#FFFBF7` | 图谱画布背景、页面底色 |
| 辅助色 | 中灰 | `#64748B` | 未选中文字、次要信息 |
| 文字色 | 深灰 | `#374151` | 卡片内正文、界面标签 |

### 2.3 渐变与阴影

- 节点填充使用纯色，无需渐变，保持简洁现代感。
- 每个节点统一添加柔和投影，增强层级浮起感：
  - 声母节点：`box-shadow: 0 4px 14px rgba(255, 154, 162, 0.4)`
  - 韵母节点：`box-shadow: 0 3px 10px rgba(181, 234, 215, 0.45)`
  - 拼音节点：`box-shadow: 0 2px 8px rgba(255, 218, 193, 0.5)`

### 2.4 应用示例

```
声母节点：圆形，#FF9AA2 填充，白色文字 "b"
韵母节点：圆形，#B5EAD7 填充，白色文字 "a"
拼音节点：圆形，#FFDAC1 填充，白色上下结构文字 "bā / 八"
```

## 3. 交互方案：韵母扇形放射展开

### 3.1 交互流程

1. **默认状态**：图谱显示当前声母 + 环绕的韵母节点，拼音节点默认隐藏（与现有「显示汉字」逻辑一致）。
2. **点击韵母节点**：
   - 该韵母节点轻微放大并高亮（描边加粗）。
   - 属于该韵母的所有拼音节点（含四个声调）以扇形从韵母节点向外展开。
   - 其他未选中的韵母节点保持可见，但透明度降低至 0.4，避免视觉干扰。
   - 展开的拼音节点通过动画从韵母位置平滑移动到目标位置。
3. **再次点击已展开韵母**：收起该韵母下的拼音节点，恢复默认状态。
4. **切换声母**：展开状态重置，新声母的韵母节点默认收起。

### 3.2 布局参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 扇形张角 | 60° ~ 90° | 根据拼音节点数量动态调整，4 个声调时约 70° |
| 展开半径 | 韵母半径 + 80px | 拼音节点距离韵母节点的默认距离 |
| 节点间距 | ≥ 16px | 通过力导向碰撞检测保证 |
| 动画时长 | 400ms | 使用 ease-out 缓动 |
| 非选中韵母透明度 | 0.4 | 保持上下文可见但弱化 |

### 3.3 状态标识

- 展开态韵母节点添加白色描边（2px）或轻微外发光，明确标识当前展开项。
- 展开的拼音节点与韵母节点之间的连线颜色加深，增强关联感。

### 3.4 与「显示汉字」的关系

- 韵母展开操作与「显示/隐藏汉字」是独立的：
  - 用户可以先点击「显示汉字」展示全部拼音节点，再点击某个韵母进行聚焦展开。
  - 也可以在隐藏汉字状态下，点击韵母只查看该韵母的拼音节点。
- 展开态优先于全局显示：当某个韵母展开时，其他韵母的拼音节点即使全局显示也暂时淡出。

## 4. 视觉与动画规范

### 4.1 节点文字排版

延续现有实现：
- 声母/韵母：单行文字，节点中心水平和垂直居中。
- 拼音节点：上下结构，拼音在汉字正上方；多字时按列横向排列。

### 4.2 过渡动画

- 韵母展开/收起：拼音节点位置使用力导向图的 `d3ReheatSimulation` 配合自定义目标位置实现平滑动画。
- 透明度变化：非选中韵母淡出/淡入 300ms。
- 节点高亮：选中韵母描边宽度从 0 到 2px，200ms。

---

## 5. 响应式适配

- **桌面端**：扇形展开空间充足，可展示完整 4 个声调节点。
- **平板端**：适当缩小展开半径，保持节点不重叠。
- **手机端**：
  - 优先展开至屏幕可用空间较大的方向。
  - 若空间不足，可考虑将展开的拼音节点排列为半圆或竖列。
  - 触摸目标不小于 44px。

## 6. 实现要点

### 6.1 色彩替换

- 在 `src/utils/pinyin-utils.js` 中定义新的 `LAYER_COLORS` 常量。
- 在 `src/components/graph/PinyinGraph.jsx` 中，声母/韵母/拼音节点统一使用 `getLayerColor(layer)` 获取颜色。
- 保留旧的 `SHENGMU_COLORS` 作为历史兼容，不再用于图谱主视觉。

### 6.2 展开交互实现

- 在 `PinyinGraph` 组件中新增状态 `expandedYunmu: string | null`，记录当前展开的韵母 ID。
- 构建 `graphData` 时：
  - 若 `expandedYunmu` 为空，所有拼音节点按现有逻辑生成但位置可折叠至韵母节点处。
  - 若 `expandedYunmu` 有值，仅该韵母对应的拼音节点移动到扇形展开位置，其余拼音节点透明度设为 0 或不可见。
- 点击韵母节点时切换 `expandedYunmu` 状态，并触发力模拟重新加热。
- 移除 `YunmuCard` 弹窗组件，或改为仅在桌面端作为辅助详情面板使用。

### 6.3 动画细节

- 使用 `react-force-graph-2d` 的 `d3ReheatSimulation()` 在展开/收起时重新启动力模拟。
- 为展开的拼音节点设置 `fx/fy` 目标坐标，使其在动画期间被力导向牵引到扇形位置。

## 7. 验收标准

- [ ] 声母、韵母、拼音节点分别使用统一的新配色。
- [ ] 同一层级内颜色一致，不再按声母变化。
- [ ] 点击韵母后，对应拼音节点以扇形展开，动画流畅。
- [ ] 未选中韵母在展开态下淡化显示。

- [ ] 切换声母后展开状态重置。
- [ ] 节点内文字保持清晰可读（白色文字 + 阴影）。
- [ ] 手机端展开不重叠、可点击。

## 8. 设计说明

- 选择「柔和马卡龙」色系是因为目标用户为 5-8 岁儿童，低饱和暖色调能降低视觉疲劳，同时保持学习工具的趣味性。
- 选择「扇形放射展开」是因为它与力导向图谱的放射状结构天然契合， children's exploration mental model（探索式心智模型）强，不需要引入额外的侧边栏或弹窗，保持界面简洁。
- 三个层级颜色在色环上大致等距分布（红/绿/橙），确保层级区分明确；同时都属于暖调马卡龙色系，整体视觉和谐统一。
